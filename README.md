# Pellucid Annotator

Annotation toolkit and validation schema for the Pellucid labelling service.

**Repository Status:** Released (v0.9.1, published 2026-07-09)

## Contents

- `src/pellucid/annotator.py`
- `src/pellucid/schema.py`
- `requirements.txt`

## Quick start

```bash
pip install -r requirements.txt
python -m pellucid.annotator --records records.jsonl
```
